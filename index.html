🔵 Graph Structure

1. Vertex

ฟุตบอล

แบดมินตัน
เทนนิส
วอลเลย์บอล
ฟุตซอล

2. Edge

ความสัมพันธ์ระหว่าง Vertex มีทั้งหมด 8 เส้น


1. ฟุตบอล ↔ บาสเกตบอล
2. ฟุตบอล ↔ แบดมินตัน
3. ฟุตบอล ↔ วอลเลย์บอล
4. บาสเกตบอล ↔ แบดมินตัน
5. บาสเกตบอล ↔ เทนนิส
6. แบดมินตัน ↔ เทนนิส
7. เทนนิส ↔ วอลเลย์บอล
8. วอลเลย์บอล ↔ ฟุตซอล

3. Adjacency List

รายการ Vertex ที่เชื่อมต่อกันใน Graph


4. ตัวอย่าง Path

ตัวอย่างการเดินจากกีฬาเริ่มต้นไปยังอีกกีฬา


ฟุตบอล → บาสเกตบอล → เทนนิส
ความหมาย: สามารถเดินจาก Vertex ฟุตบอล ไปยังเทนนิสผ่านบาสเกตบอล
